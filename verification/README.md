# Verification records

For instructions to reproduce and interpret these checks, see
[VERIFY.md](../VERIFY.md). For the definitions review, see
[HUMAN-CHECK.md](../HUMAN-CHECK.md).

`2026-10-05/` preserves the original publication artifact run: all 43 frozen
project modules were freshly compiled, the exact theorem target and axioms
were checked, and kernel replay passed. The provider was the research
workspace's Lean project with existing external package binaries.

`2026-10-07/` records verification from this standalone publication folder.
The same frozen proof sources are compiled into a new temporary output
directory. The provider again supplies existing pinned external packages;
the research workspace's project proof caches are excluded.

Each run contains `environment.json`, `builds.json`, `type_axioms.json`,
`kernel_replay.json`, `result.json`, and the corresponding text logs.
`environment.json` records the external package revisions, Lean executable
hashes, and excluded cache paths. These records describe the environment
actually used and retain its original absolute paths.

`human-statement.log` contains the target, key definitions, and axiom list
printed by `artifact/ReadStatement.lean` against the freshly compiled modules.
`human-statement-check.json` records that command and its successful exit.
`manuscript-build.log` records the standalone LaTeX build of the current
manuscript, including its public availability statement; the resulting PDF
was also checked by extracting its text.

Compiled project binaries are regenerated by `verify_artifact.py` and are
excluded from the release. External dependency binaries were retained during
the recorded checks; the verifier does not rebuild or replay those packages.
